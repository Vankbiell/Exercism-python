# Bob

Bem-vindo ao Bob na trilha Python do Exercism.
Se você precisar de ajuda para rodar os testes ou enviar seu código, confira o `HELP.md`.

## Introduction

Bob é um adolescente [apático][lackadaisical].
Ele gosta de pensar que é muito descolado.
E definitivamente não se empolga com as coisas.
Isso não seria descolado.

Quando as pessoas falam com ele, as respostas são bem limitadas.

[lackadaisical]: https://www.collinsdictionary.com/dictionary/english/lackadaisical

## Instructions

Sua tarefa é determinar o que o Bob vai responder quando alguém diz algo para ele ou faz uma pergunta.

O Bob só responde uma de cinco coisas:

- **"Sure."**
  Esta é a resposta dele quando você faz uma pergunta, como "How are you?"
  A convenção para perguntas é que elas terminam com um ponto de interrogação.
- **"Whoa, chill out!"**
  Esta é a resposta dele quando você GRITA COM ELE.
  A convenção para gritar é escrever TUDO EM LETRAS MAIÚSCULAS.
- **"Calm down, I know what I'm doing!"**
  É isso que ele diz quando você grita uma pergunta para ele.
- **"Fine. Be that way!"**
  É assim que ele responde ao silêncio.
  A convenção para o silêncio é nada, ou várias combinações de caracteres de espaço em branco.
- **"Whatever."**
  É isso que ele responde a qualquer outra coisa.
