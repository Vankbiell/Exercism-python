## Introduction

Um ano bissexto (no calendário gregoriano) acontece:

- Em todo ano que é divisível por 4.
- A menos que o ano seja divisível por 100, caso em que só é bissexto se também for divisível por 400.

Alguns exemplos:

- 1997 não foi um ano bissexto, pois não é divisível por 4.
- 1900 não foi um ano bissexto, pois não é divisível por 400.
- 2000 foi um ano bissexto!
